## Union exercise
The instrument file union_exercise contains an instrument with a number of Union materials, a transmission detector and a banana detector.

## Exercise
In this exercise you should build an interesting system using the Union geometry components. Use the object parameters to size the monitors to the object you have made.
- Try to make a layered geometry using the priority system, higher priorities win in case of overlap

## Hints
- The intersection algorithm does not support tangential faces, if neutrons are lost, thats probably the cause
- Use mcdoc to see all the parameters of the geometry components
