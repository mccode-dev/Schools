## Exercise
This folder have the example instruments for Res_sample / Res_monitor and for TOFRes_sample / TOFRes_monitor. 

- Choose one and perform a simulation
- Use the terminal tool mcresplot tool on the approrpiate datafile 
    - reso.dat for Res_sample
    - TOFres.dat for TOFRes_sample
- Change instrument parameters and see how the resolution changes

### Resolution on large detector example
A prototype workflow for resolution / point spread function on a large detector is also included in a folder, you can play with that notebook too.
